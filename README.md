# Concurso Navideño de Programación Competitiva de Interclubes 2026

Página de la **convocatoria general**. La convocatoria específica de cada sede queda a cargo del jefe de sede.

## Publicar con GitHub Pages

1. Sube el contenido de esta carpeta a la raíz del repositorio (`index.html` debe quedar en la raíz).
2. En el repositorio, entra a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**.
4. Selecciona la rama `main`, la carpeta `/ (root)` y presiona **Save**.
5. Espera unos minutos. La página quedará en `https://club-de-algoritmia-acatlan-guapa.github.io/miscelanea-guapa/`.

## Archivos

| Ruta | Contenido |
| :-- | :-- |
| `index.html` | Texto de la página, clubes y sedes |
| `styles.css` | Colores, tipografía y diseño |
| `script.js` | Contador al inicio del concurso y fechas que ya pasaron |
| `assets/logos/` | Logotipos recortados de los clubes |
| `assets/fonts/` | Tipografías (SIL Open Font License) |

## Cambios frecuentes

- **Agregar un club:** guarda su logo en `assets/logos/`, copia un `<li>` de la lista `esferas` en `index.html` y cambia imagen y nombre. Usa la clase `redondo`, `cuadrado` o `ancho` según la forma del logo.
- **Agregar una sede:** añade un `<li>` en la lista `sedes` de `index.html`.
- **Cambiar fechas:** edítalas en `index.html` y también en `script.js`.
